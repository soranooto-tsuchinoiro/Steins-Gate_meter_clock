# Divergence Meter Clock

一个基于《命运石之门》(Steins;Gate)的世界线变动率探测器桌面应用程序。该应用可以在桌面上显示数字时钟或模拟世界线变动的随机数字，支持自动报时和手动触发功能。

## 项目简介

Divergence Meter Clock 是一款致敬《命运石之门》的桌面小工具，它可以：

- **当前时间显示**：以辉光管风格显示当前时间（HH.MM.SS）
- **世界线变动率**：模拟世界线变动率探测器，显示来自不同吸引力场域（α、β、Steins Gate等）的世界线数值
- **自动报时**：在整点和半点前后自动弹出显示
- **系统托盘**：最小化到系统托盘，支持常显模式和报时模式切换
- **可配置参数**：支持自定义报时时间、闪动效果等参数

## 安装和运行

### 1. 克隆或下载项目
```bash
git clone https://github.com/soranooto-tsuchinoiro/Steins-Gate_meter_clock.git
cd Steins-Gate_meter_clock
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

或手动安装：
```bash
pip install PyQt5 Pillow
```

### 3. 准备资源文件
确保项目根目录下存在 `img` 文件夹，其中包含以下数字图片文件：
- `0.jpg` 到 `9.jpg`（数字0-9的尼克西管样式图片）
- `.jpg`（小数点图片）
- `null.jpg`（空白分隔符图片）

可选：在 `assets` 文件夹中放置 `logo.ico` 作为系统托盘图标。

### 4. 运行程序
```bash
python main.py
```

## 代码架构

### 模块说明

#### 1. **main.py** - 程序入口
- 创建Qt应用实例
- 初始化主窗口
- 根据当前时间决定初始显示状态

#### 2. **main_window.py** - 主窗口
- 继承自 `FramelessWindow`
- 管理窗口显示和隐藏
- 处理用户交互（键盘、鼠标）
- 控制自动报时逻辑
- 集成托盘图标、时间管理器等组件

#### 3. **config.py** - 配置管理
- 管理所有可配置参数
- 支持配置的读取、写入和持久化
- 配置文件存储在 `~/.Steins-Gate_meter_clock/config.ini`

#### 4. **constants.py** - 常量定义
- 定义显示模式（时钟/世界线）
- 定义UI参数（刷新间隔、图标大小等）
- 定义世界线数据（各吸引力场域的数值）

#### 5. **image_utils.py** - 图片处理
- `ImageOptionMixin`：提供图片拼接等基础操作
- `ImageGenerator`：生成时钟和世界线图片序列

#### 6. **threads.py** - 后台线程
- `ImageThread`：在独立线程中生成图片
- 通过Qt信号将图片数据传递给主窗口
- 避免阻塞UI主线程

#### 7. **time_manager.py** - 时间管理
- 判断当前是否在显示窗口内
- 判断是否应该触发世界线变动
- 支持自定义报时时间节点

#### 8. **tray_icon.py** - 系统托盘
- 创建和管理系统托盘图标
- 提供右键菜单（切换模式、设置、退出）
- 支持常显模式和报时模式切换

#### 9. **ui_components.py** - UI基础组件
- `FramelessWindow`：无边框可拖拽窗口基类
- 支持窗口拖动、调整大小
- 始终置顶、不抢占焦点等特性

#### 10. **settings_window.py** - 设置对话框
- 提供用户友好的参数配置界面
- 配置闪动效果、报时时间等参数

## 使用说明

### 自动报时模式（默认）

程序启动后会自动在以下时间显示：
- **整点报时**：每小时的 `X:59:50` 至 `X:00:10`（共20秒）
- **半点报时**：每小时的 `X:29:50` 至 `X:30:10`（共20秒）

如果启用了"报时前世界线变动"选项，程序会在 `X:59:50` 和 `X:29:50` 时先显示世界线变动动画。

### 手动控制

#### 系统托盘菜单
右键点击系统托盘图标可以访问以下选项：
- **切换常显模式/切换报时模式**：在常显和自动报时模式之间切换
- **报时前世界线变动**：勾选后，报时前会先显示世界线变动动画
- **设置参数**：打开参数配置对话框
- **退出**：关闭应用程序

#### 窗口交互
- **左键拖动**：移动窗口位置
- **右键点击**：手动触发世界线变动模式（显示指定时长的随机数字）
- **双击**：切换最大化/正常大小
- **拖动右下角**：调整窗口大小
- **按任意键**：隐藏窗口

### 配置选项

#### 通过设置对话框配置
在系统托盘右键菜单中选择"设置参数"可以配置：
- **闪动间隔时间**：世界线快速闪动的间隔（10-1000毫秒）
- **闪动总持续时间**：世界线模式的总显示时长（1000-20000毫秒）
- **报时时间节点**：自定义报时的分钟数，如 "0,30" 表示整点和半点

#### 通过代码配置
在 `constants.py` 中可以自定义更多参数：

```python
# UI刷新参数
MAIN_TIMER_INTERVAL_MS = 100        # 主定时器间隔（毫秒）
CLOCK_FRAME_INTERVAL_MS = 500       # 时钟刷新间隔（毫秒）

# 功能开关
TRIGGER_METER_BEFORE_ANNOUNCE = True  # 报时前是否先触发世界线变动
SHOW_WITHOUT_ACTIVATING = True        # 显示时不抢占焦点

# 托盘图标
TRAY_ICON_SIZE = 64                  # 托盘图标大小（像素）
```

### 世界线说明

程序内置了《命运石之门》中的多个吸引力场域世界线：
- **α世界线** (Alpha)
- **β世界线** (Beta)
- **R世界线**
- **χ世界线** (包含 Steins;Gate 世界线 1.048596)
- **γ世界线** (Gamma)
- **δ世界线** (Delta)
- **ε世界线** (Epsilon)

在世界线模式下，程序会从这些预定义的数值中随机选择并显示。

## 常见问题

### Q1: 程序启动后看不到窗口？
**A:** 这是正常现象。在报时模式下，程序只在整点和半点前后自动显示。您可以：
- 等待下一个报时时间（如14:59:50或15:29:50）
- 右键点击系统托盘图标，选择"切换常显模式"以持续显示

### Q2: 如何自定义窗口大小和位置？
**A:** 有两种方法：
1. 在窗口显示时，左键拖动可移动位置，拖动右下角可调整大小（会自动保存）
2. 直接编辑配置文件 `~/.Steins-Gate_meter_clock/config.ini`

### Q3: 数字图片显示不正常或缺失？
**A:** 请确保 `img` 文件夹包含所有必需的图片文件（0.jpg到9.jpg、.jpg、null.jpg）。图片格式应为JPG，且尺寸应保持一致。

### Q4: 如何修改报时时间？
**A:** 两种方法：
1. 右键托盘图标 → 设置参数 → 修改"报时时间节点"
2. 编辑 `~/.Steins-Gate_meter_clock/config.ini` 中的 `display_minutes` 参数

### Q5: 程序占用CPU较高怎么办？
**A:** 可以调整以下参数来降低资源占用：
- 在设置对话框中增加"闪动间隔时间"
- 在 `constants.py` 中增加 `MAIN_TIMER_INTERVAL_MS` 和 `CLOCK_FRAME_INTERVAL_MS`
- 在不需要显示时切换到报时模式

### Q6: 如何添加自定义的世界线数值？
**A:** 在 `constants.py` 中找到世界线定义部分，按照相同格式添加自定义数值元组，然后将其添加到 `ATTRACTOR_FIELD` 集合中。

### Q7: 窗口总是显示在最前面，影响其他操作？
**A:** 这是设计特性（类似于真实的桌面小工具）。如果需要临时隐藏，可以按任意键或右键托盘图标选择隐藏。若要永久改变此行为，需修改 `ui_components.py` 中的 `Qt.WindowStaysOnTopHint` 标志。

### Q8: 程序能在macOS/Linux上运行吗？
**A:** 可以。程序使用PyQt5开发，支持跨平台运行。但系统托盘图标在不同平台上的显示效果可能略有差异。

## 开发说明

### 代码规范
- 所有方法都采用外部文档字符串（docstring）格式
- 按照业务逻辑和调用顺序组织方法
- 使用分隔注释区分不同功能模块
- 私有方法以下划线 `_` 开头
- 类型提示使用 Python 3.8+ 语法

### 方法组织原则
1. **初始化方法**：`__init__` 和相关的 `_init_*` 方法
2. **私有方法**：以 `_` 开头的内部方法
3. **公共方法**：对外提供的接口方法
4. **事件处理方法**：各类事件的回调方法

### 扩展开发
如需扩展功能，建议遵循以下模式：
1. 在 `constants.py` 中添加新的常量定义
2. 在 `config.py` 中添加新的配置项
3. 在相应的模块中实现新功能
4. 在 `main_window.py` 中集成新功能
